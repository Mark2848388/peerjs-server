AZENA — сервер видеозвонка

1. Создай GitHub-репозиторий, например azena-video-server.
2. Загрузи в него ТОЛЬКО содержимое папки server:
   package.json
   server.js
3. Открой Railway и создай New Project.
4. Выбери Deploy from GitHub repo и укажи этот репозиторий.
5. Railway определит Node.js-проект и выполнит установку зависимостей.
6. После успешного Deploy открой Settings → Networking → Generate Domain.
7. Скопируй полученный адрес вида:
   https://ИМЯ.up.railway.app
8. В client/app.js замени:
   const SIGNALING_SERVER = "https://YOUR-RAILWAY-DOMAIN.up.railway.app";
   на свой настоящий адрес.
9. Для фронтенда можно пока использовать Acode Preview. Для полноценного публичного сайта позже тоже разместим client на хостинге.

ВАЖНО:
- Сервер НЕ передаёт само видео. Он только помогает двум браузерам обменяться WebRTC-сигналами.
- Видео и звук идут напрямую между браузерами, когда сеть это позволяет.
- Для некоторых мобильных/корпоративных сетей позже понадобится TURN-сервер. Это отдельный этап.
- Видеозвонок рассчитан на 2 человека в комнате.
- Камера и микрофон требуют HTTPS или localhost. После публикации фронтенда по HTTPS браузер сможет запросить разрешения.
